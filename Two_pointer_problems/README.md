# Two-Pointer Problems

This folder contains palindrome, pair-sum, and Two Sum exercises. The examples demonstrate different contracts: some return values, some return input indices, and the medium Two Sum example requires a sorted input.

Read each function's docstring for its assumptions, return format, and complexity. Run the automated checks from the repository root with:

```bash
python -m unittest discover -s tests -v
```

See the [repository guide](../README.md#adding-a-solution) for the format to use when adding an exercise.
