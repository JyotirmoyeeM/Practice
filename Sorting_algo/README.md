# Sorting Algorithms

This folder contains ascending bubble, optimized bubble, insertion, and selection sort examples, plus a descending bubble sort.

The functions sort their input list in place and return it. Compare each approach's time and extra-space complexity in the source docstrings. Run the automated checks from the repository root with:

```bash
python -m unittest discover -s tests -v
```

See the [repository guide](../README.md#adding-a-solution) for the format to use when adding an exercise.
